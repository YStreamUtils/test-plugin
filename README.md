## The Stream Companion Example Plugin You Didn't Ask For

This repo is a test plugin, it currently has the theoretically worst case scenario (ts + imports) the application can support.

You can either clone this repo or use it as a template. It should be fine either way.

If you want to check what capabilities a plugin currently has access to, I would refer you to:

- [The host.d.ts file in this repo](https://github.com/YStreamUtils/test-plugin/blob/main/src/host.d.ts)
- [The host.d.ts file in main repo](https://github.com/YStreamUtils/YStreamUtils/blob/main/host.d.ts)
- [The permissions in the main repo](https://github.com/YStreamUtils/YStreamUtils/blob/main/internal/models/permissions.go)

I'll try and update this whenever I make a change.

## [For deploying, please check the plugin registry repo](https://github.com/YStreamUtils/YStreamUtils-Plugin-Registry)
